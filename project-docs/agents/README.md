# Agent Role Cards

Use these role cards when content is drafted or reviewed by AI agents. They are required for both new builds and WordPress -> Astro + Sanity migrations.

- `mitch-writer-agent.md` / `mitch.writer.toml`: source-grounded content planner and section-ready draft writer.
- `charlie-editor-agent.md` / `charlie.editor.toml`: editor, SEO reviewer, and Sanity section QA gate.

Mitch drafts first. Charlie reviews second. Charlie can approve, request revision, or block content that creates SEO risk, unsupported claims, raw HTML debt, or section-contract mismatches.
