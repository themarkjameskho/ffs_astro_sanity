07

SEO Technical Baseline

Pre-Launch Checklist
  • Canonical tags self-referencing on all pages
  • Title tags: unique per page, 50–60 chars, keyword-first
  • Meta descriptions: unique per page, 150–160 chars
  • H1: one per page, matches primary keyword intent
  • Schema markup: LocalBusiness on HP, service schema on SP/SLP, FAQPage on FAQ sections, BreadcrumbList on all inner pages
  • XML sitemap auto-generated by Astro integration
  • robots.txt configured correctly
  • Image alt text on all images (Sanity field required)
  • Core Web Vitals: LCP < 2.5s · CLS < 0.1 · INP < 200ms
  • Mobile-first responsive — test all breakpoints
  • NAP consistent across all pages — matches GBP exactly
  • All phone numbers use href="tel:" for tap-to-call
  • Google Analytics 4 firing on all pages — [GA4 ID pending]
  • Google Search Console verified post-launch — [pending]
  • Fieldroutes portal link functional — [embed pending]
  • Contact form submissions tested end-to-end
  • CallRail dynamic number insertion active
