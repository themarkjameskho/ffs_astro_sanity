# Track: Landing Page / Microsite

Use this track for a campaign page, paid-media destination, GBP-focused page, or small microsite. It is a scope profile, not a different rendering architecture.

## Required inputs

- Campaign/project brief: audience, offer, conversion goal, allowed claims, primary CTA, secondary CTA policy, form/phone destination, tracking and approval owner.
- Reference set and the approved design-system variant.
- Page content architecture: H1, section sequence, rich-text bodies, list/CTA hierarchy, SEO metadata, canonical strategy, and component map.
- Scope boundaries: page count, navigation/footer relationship, index/noindex decision, analytics, launch domain/path, and expiry/retirement plan.

## Classification rule

- A genuinely new campaign destination follows the Fresh Build track plus this scope profile.
- A replacement for an existing URL, an indexed landing page, or a page inheriting WordPress content follows the WordPress Migration track plus this scope profile.

## Implementation rule

Use the same Sanity page documents, canonical renderer, shared components, design tokens, forms, and verification rules as a full site. A landing page does not authorize a custom one-off template or hardcoded marketing section.

**Gate:** HOLD if conversion destination, indexing/canonical policy, or form/tracking ownership is unknown.
